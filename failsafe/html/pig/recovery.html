Install a P5 factory UBI image for the current flash layout. This replaces firmware and settings.

   
Maximum upload: 32 MiB. Requires a P5 FIT and UBI volumes kernel, rootfs, and empty autoresizing rootfs_data.

   
Single-layout flashing was hardware-tested. Dual-layout flashing was tested only in simulation.

After conversion, restart and install firmware for the selected layout.
